# Бот сообщений Авито

Telegram-бот, который отвечает заранее заготовленными клише по нишам на обращения
в чатах ваших объявлений на Авито и досылает follow-up тем, кто перестал отвечать.
Работает через **официальный API Авито** (`api.avito.ru`).

## Что умеет

- **Ниши.** Например «Квартиры · сдача · длительно · собственники». У ниши есть
  ключевые слова; чат относится к нише, если **все** её слова встречаются в
  заголовке объявления. Одна ниша помечается как «по умолчанию» — на неё падают
  чаты, не подошедшие ни под одну другую.
- **Клише.** Для каждой ниши два типа: `автоответ` (на первое обращение) и
  `follow-up` (если человек замолчал дольше N часов). Плейсхолдеры:
  `{item_title}`, `{item_id}`, `{interlocutor}`, `{niche}`, `{account}`.
- **Несколько аккаунтов Авито.** Добавляются в боте (`client_id` / `client_secret`),
  активный переключается одной кнопкой. Секреты шифруются в БД (Fernet).
- **Лимит 50 сообщений в сутки** (меняется в боте), пауза между сообщениями,
  пауза всей отправки, очередь и история отправок.
- **Дедупликация.** В один чат уходит не больше одного автоответа и одного
  follow-up — повторный опрос ничего не задваивает.
- **DRY-RUN.** Встроенный симулятор Авито: вся цепочка проверяется без реальной
  отправки и без ключей API.

## Чего бот не делает

Он **не рассылает сообщения по чужим объявлениям**. Официальный API Авито
позволяет писать только в уже существующие чаты (то есть тем, кто обратился к вам
сам), и обходить это ограничение бот не пытается: никакой авторизации в обход API,
подмены аккаунтов и ротации прокси под лимиты здесь нет.

`PROXY_URL` — это обычная сетевая настройка HTTP-клиента для закрытого контура,
а не средство обхода ограничений площадки.

## Быстрый старт (проверка работоспособности)

Ключи Авито не нужны — проверка идёт в режиме `DRY_RUN=1` на встроенном симуляторе.
Нужен только токен бота от [@BotFather](https://t.me/BotFather) (команда `/newbot`)
и ваш Telegram ID от [@userinfobot](https://t.me/userinfobot).

### Шаг 1. Установить Python и Git

- **Windows:** [python.org/downloads](https://www.python.org/downloads/) — при установке
  обязательно поставьте галочку **«Add python.exe to PATH»**.
  Затем [git-scm.com/download/win](https://git-scm.com/download/win) (всё по умолчанию).
- **macOS:** установите [Homebrew](https://brew.sh), затем в Терминале:
  `brew install python git`
- **Linux (Ubuntu/Debian):** `sudo apt install python3 python3-venv git`

### Шаг 2. Открыть терминал

- **Windows:** `Win + R` → напечатать `powershell` → Enter.
- **macOS:** `Cmd + Space` → напечатать `Терминал` → Enter.
- **Linux:** `Ctrl + Alt + T`.

### Шаг 3. Выполнить команды

Копируйте построчно, после каждой — Enter:

```bash
git clone https://github.com/Nastyface144/-.git avito-bot
cd avito-bot
git checkout claude/peaceful-wozniak-jbwywm
python start.py
```

На Windows, если `python` не находится, используйте `py start.py`;
на macOS и Linux — `python3 start.py`.

`start.py` сам поставит зависимости, спросит токен и ваш ID, сгенерирует
`SECRET_KEY`, проверит связь с Telegram и запустит бота. Больше ничего вводить
не нужно. Повторный запуск — та же команда `python start.py` из папки `avito-bot`
(вернуться в неё: `cd avito-bot`).

### Что дальше

Бот работает, пока открыто окно терминала. Закрыли — бот выключился,
запустить снова той же командой. Для круглосуточной работы см. «Боевой режим».

### Ручная установка

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
python tools/gen_key.py          # положите вывод в SECRET_KEY
# впишите в .env: BOT_TOKEN и ADMIN_IDS

python -m avito_bot --check      # предполётная проверка
python -m avito_bot              # запуск
```

`python -m avito_bot --check` проверяет настройки, связь с Telegram (покажет
`@username` вашего бота), базу и — в боевом режиме — доступ к API Авито.

Дальше — в Telegram:

1. `/start` → **👤 Аккаунты** → «Добавить аккаунт». В DRY-RUN значения
   `client_id` / `client_secret` могут быть любыми.
2. **🎯 Ниши** — стартовая ниша «Квартиры · сдача · длительно · собственники»
   уже создана вместе с парой клише; можно добавить свои.
3. **💬 Клише** — посмотреть и отредактировать тексты.
4. **🧪 Демо**:
   - «Новое входящее» → введите заголовок объявления, например
     `Сдам квартиру, 2-к, длительно, от собственника`;
   - «Опросить чаты сейчас» → бот подберёт нишу и поставит клише в очередь;
   - «Отправить из очереди» → отправка с учётом лимита (в Авито ничего не уходит);
   - «Состарить чаты на 48ч» → затем снова «Опросить» — встанет follow-up.
5. **📊 Статистика** и **📮 Очередь** покажут, что именно и когда ушло.

Автоматические тесты (без сети и без Telegram):

```bash
pip install -r requirements-dev.txt
pytest -q
```

## Боевой режим

1. В личном кабинете Авито создайте приложение и получите `client_id` /
   `client_secret` (раздел «Настройки → Доступ к API»).
2. В `.env` поставьте `DRY_RUN=0`, задайте `SECRET_KEY`.
3. Добавьте аккаунт в боте и нажмите «🔌 Проверить» — бот получит `user_id`
   и покажет число доступных чатов.
4. Запустите одним из способов:
   - `docker compose up -d --build` — в Docker;
   - через systemd: шаблон и инструкция в `deploy/avito-bot.service`.

Боту нужен постоянно работающий компьютер или VPS: пока процесс не запущен,
он не отвечает и не отправляет сообщения.

## Безопасность

- `BOT_TOKEN` и ключи Авито живут только в `.env` на вашей машине
  (`.env` в `.gitignore`, `start.py` ограничивает права на файл).
  Не пересылайте их в переписке — токен даёт полный доступ к боту.
  Если токен всё же засветился, в @BotFather команда `/revoke` выдаст новый.
- `SECRET_KEY` шифрует `client_secret` аккаунтов в базе. Потеряете ключ —
  аккаунты придётся добавить заново.
- Бот отвечает только тем, чьи ID перечислены в `ADMIN_IDS`.

## Настройки (.env)

| Переменная | Смысл | По умолчанию |
| --- | --- | --- |
| `BOT_TOKEN` | токен Telegram-бота | — |
| `ADMIN_IDS` | id админов через запятую; остальным бот не отвечает | — |
| `DRY_RUN` | `1` — симулятор вместо реального API | `1` |
| `DAILY_LIMIT` | лимит сообщений в сутки на аккаунт | `50` |
| `SEND_INTERVAL_SECONDS` | пауза между сообщениями | `45` |
| `POLL_INTERVAL_SECONDS` | как часто опрашивать чаты | `60` |
| `FOLLOWUP_AFTER_HOURS` | через сколько часов молчания слать follow-up | `24` |
| `DB_PATH` | файл SQLite | `data/bot.sqlite3` |
| `SECRET_KEY` | ключ Fernet для секретов аккаунтов | — |
| `AVITO_API_BASE` | базовый URL API | `https://api.avito.ru` |
| `PROXY_URL` | HTTP-прокси для запросов к API | — |

Лимит, интервалы и период follow-up меняются прямо в боте (**⚙️ Настройки**) —
значения из `.env` используются как стартовые.

## Как устроено

```
avito_bot/
  config.py            настройки из .env
  crypto.py            шифрование client_secret
  db.py                SQLite: аккаунты, ниши, клише, чаты, очередь отправок
  avito/
    client.py          официальный API: токен, чаты, сообщения, отправка
    fake.py            симулятор для DRY-RUN
    models.py          разбор ответов API
  services/
    templates.py       подбор ниши по заголовку, подстановка плейсхолдеров
    poller.py          опрос чатов → постановка клише в очередь
    sender.py          отправка с суточным лимитом и темпом
    gateways.py        выбор клиента (реальный/симулятор) и его кэш
  bot/                 хендлеры, клавиатуры, состояния диалогов
  main.py              запуск бота и двух фоновых задач
start.py               установка и запуск одной командой
```

Версии эндпоинтов мессенджера собраны в константах вверху
`avito_bot/avito/client.py` — если Авито поменяет пути, править нужно только там.
